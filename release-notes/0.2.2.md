UnraidClaw 0.2.2 fixes saving keys on the App Keys tab and makes app API calls visible in the activity log.

## Security and reliability fixes

- Saving a key on the **App Keys** tab no longer fails with "Error: HTTP 200". The settings page read Unraid's CSRF token from the wrong place, which went unnoticed because nothing on the page used POST before. It now uses `csrf_token` from `var.ini`, as Unraid's own pages do.

## Other changes

- The activity log shows what an app API call sent, such as `DELETE /api/albums/42` or `dry run POST /api/albums`, next to the route. Saved keys are redacted from query strings, and the detail is cut off at 200 characters.
