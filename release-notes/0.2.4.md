UnraidClaw 0.2.4 fixes three problems with host devices on full installs and template edits, found by dry-running a real Community Applications template.

## Security and reliability fixes

- A device of `/dev` or `/dev/` is refused. Templates use `/dev/` as a placeholder for "pick your device", and docker would pass every device on the host for it. A device must name something under `/dev`, such as `/dev/ttyUSB0` or `/dev/dri`.
- A device overridden to `""` is left out of the template. Unraid's command builder turns an empty device into `--device=''`, which docker refuses.
- An override for one device of a template with several no longer sets all of them. Devices have no container-side target, so overrides are now matched to them by the field's name.
