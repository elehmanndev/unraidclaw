UnraidClaw 0.1.37 fixes one CLI bug found while testing 0.1.36. The Unraid plugin, REST API, MCP endpoint and OpenClaw plugin are unchanged; the OpenClaw plugin stays at 0.1.16 on npm.

## Security and reliability fixes

- The CLI refused a flag value that starts with a dash, such as `unraidclaw docker create --extra-args "--gpus all"`, reporting an unknown flag. A string flag now takes a following dash word as its value, so the space form works alongside the `--extra-args="--gpus all"` form. Words after a bare `--` stay positional, a string flag with no value is still a usage error, and boolean flags never swallow the next word.

## Upgrade notes

- Only the CLI changes. Update it with `npm install -g unraidclaw-cli` or download the new archive. Updating the Unraid plugin is optional; it carries the same gateway as 0.1.36.
