UnraidClaw 0.3.0 republishes 0.2.10 under a version the Unraid plugin manager offers as an update. It also documents the version rule that caused the problem.

## Security and reliability fixes

- `POST /api/docker/containers` and `unraid_docker_create` need `template:update` as well as `docker:create` for `privileged: true`, any `devices` or a non-empty `extraArgs`, the same as a full Community Applications install. This shipped in 0.2.10, which servers on 0.2.9 were never offered.

## Upgrade notes

- Unraid compares plugin versions as text, where `0.2.10` sorts before `0.2.9`. A server on 0.2.9 showed no update for 0.2.10; 0.3.0 sorts after both. From now on every part of a version stays a single digit.
- A key or preset with `docker:create` but not `template:update`, such as **Docker Manager**, can no longer create privileged containers or pass devices or Extra Parameters.
