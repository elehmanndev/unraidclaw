UnraidClaw 0.2.10 closes a permission gap in container creation that 0.2.9 introduced.

## Security and reliability fixes

- `POST /api/docker/containers` and `unraid_docker_create` accepted privileged mode, host devices and Extra Parameters with `docker:create` alone. Each can give the container root on the host, and a full Community Applications install already needs `template:update` for them. A create request with `privileged: true`, any `devices` or a non-empty `extraArgs` now needs `template:update` as well and is refused with `403` without it. `staticIp`, `cpuset` and `postArgs` still need only `docker:create`.

## Upgrade notes

- A key or preset with `docker:create` but not `template:update`, such as **Docker Manager**, can no longer create privileged containers or pass devices or Extra Parameters. Grant `template:update` to a key that needs them.
