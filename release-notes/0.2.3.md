UnraidClaw 0.2.3 lets an agent install Community Applications apps whose templates need more than a plain container: privileged mode, Extra Parameters, host devices or a custom network.

## Highlights

### Full installs

- `unraid_ca_install` and `POST /api/ca/app/:name/install` take `full: true` to install an app with every setting its template asks for, the way the Docker tab would. The plain install still refuses these. See [Full installs](https://github.com/elehmanndev/unraidclaw#full-installs) in the README.
- Privileged mode, Extra Parameters, Post Arguments, host devices, a MAC address and custom networks such as `br0` are written into the template, and Unraid builds the container from it.
- `settings` sets template elements at install time, with the same keys `unraid_template_edit` takes, for example `{"Network": "br0", "MyIP": "192.168.1.60"}`.
- The dry-run plan lists the settings and the full template, and warns what the container will be allowed to do.

## Upgrade notes

- A full install needs `template:update` as well as `ca:create`, so the easy way to get privileged mode or devices is not a fresh install.
- A network other than bridge, host or none must exist on the server.
- Tailscale templates, templates with extra networks, and memory limits on Unraid before 7.4 are still refused: Unraid's `rebuild_container` does not set them up.
